## The entry

> It works on my machine — because my machine is the only one that never got the deploy.

One funny single-line excuse a developer gives when code breaks in production (86 characters). The oldest excuse in the book, turned inside out: the deploy never went out, so of course it works on the one machine that never received it.

## How it works

`main.py` (Python 3.13, standard library only) writes the entry text to `/output/entry.txt`, validating first that it is a single non-blank line of 1–200 characters.
